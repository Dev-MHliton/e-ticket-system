## 📖 Overview

E-Ticket System is a modern front-end ticket management application designed to simplify the process of monitoring and managing customer tickets.

The platform focuses on clean UI design, component reusability, responsive layouts, and a smooth user experience. Users can view ticket information, track ticket progress, and interact with ticket-related actions through an organized dashboard-like interface.

### 🎫 Ticket Management

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/Dev-MHliton/e-ticket-system.git
```

### Navigate to the Project Directory

```bash
cd e-ticket-system
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```
